# Nix the Cat — v0.6.1 BETA

A mobile web rhythm game starring Nix the cat. Swat snacks on the beat across 9 original songs: lo-fi, funk, EDM, drum & bass, punk, salsa, synthwave, arcade rock and reggae. It has Easy, Normal and Hard difficulties, fever mode, meow call-and-response, unlockable outfits and high scores.

**Play:** https://rainwatergames.github.io/nix-the-cat/

> ⚠️ **BETA**: this game is still in development, and things may change.

All music is original. It was composed for this game.
